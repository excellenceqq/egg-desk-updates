# Server Hopper

Компактное Windows-приложение для перехода на малозаполненные публичные серверы Roblox.

**[Скачать для Windows · ZIP](https://github.com/excellenceqq/egg-desk-updates/releases/latest/download/ServerHopper-Windows.zip)**

Распакуйте архив и откройте **ServerHopper.exe**. Для входа в игру понадобится установленный Roblox. По умолчанию выбрана **Steal an Egg**.

### Первый переход

Нажмите **Найти свободный сервер**. Приложение запросит список серверов, выберет подходящий и передаст переход Roblox. На панели появится число игроков на момент поиска. За время запуска игры состав сервера может измениться.

### Управление

| Что нужно | Где это найти |
|---|---|
| Искать по заполненности, пингу или балансу | Настройки → Режим поиска |
| Выбрать другую игру | Настройки → Place ID игры |
| Открыть панель поверх игры | Панель или **Ctrl + Alt + F8** |
| Передвинуть панель | Потяните за заголовок |
| Обновить программу | Закройте приложение и замените EXE из нового ZIP |

Тему и непрозрачность панели можно выбрать в настройках. Панель скрыта при запуске. Приложение сохраняет только настройки.

Пинг берётся из списка Roblox. Прочерк означает, что значения нет. Пустота имеет приоритет в режиме «Самые пустые». «Мин. пинг» сравнивает известные значения. «Баланс» учитывает лимит игроков и добавляет к оценке задержки 25 баллов за игрока. Глубина ограничивает число страниц одним, тремя или восемью запросами по 100 серверов.

Крестик скрывает основное окно в область уведомлений Windows. Нажмите значок для возврата, либо выберите «Выход» в его меню. В настройках оформления доступны русский и английский языки, запись своей горячей клавиши и ползунок прозрачности (0% — непрозрачная панель, 55% — самая прозрачная).
